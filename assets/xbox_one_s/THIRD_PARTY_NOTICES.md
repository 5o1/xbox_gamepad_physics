# Xbox One S input archive attribution and licenses

This zip distributes only reviewed input snapshots, provenance and license notices. The wheel builds kinematics, motion contracts, sim_visual, URDF, runtime manifests and SDF meshes locally on the user's machine. The full third-party history remains in the source repository's root THIRD_PARTY_NOTICES.md. This input archive does not distribute other controller models, the overlay or other third-party code.

License: CC BY 4.0; legal text: https://creativecommons.org/licenses/by/4.0/legalcode . The author's original GLB is unchanged. STATIC_VISUAL is a reviewed snapshot evaluated at frame 0 with world transforms baked in; meshbase is a closed-shell derivative; CoACD is the v0.2.0 convex-decomposition snapshot. See each directory's README/manifest for specific modifications. No calibration against physical mechanics or contact behavior is claimed.
