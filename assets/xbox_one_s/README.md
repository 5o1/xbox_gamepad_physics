`source/xbox_one_s_controllergamepad_animated.glb` is the unchanged original 2K GLB.
SHA-256: `5c5671c83a9cf15db4b8399e7010aa7d5cde915687ceb348b583eb00b0ed24e2`.

`visual/` contains the static GLB, 16 separate OBJ files and `inventory.json` used for the current preview.
The derivative evaluates frame 0 of the original model and bakes part transforms into world coordinates, with no decimation or scale fitting.
The static GLB retains materials and embedded textures; the OBJ files contain geometry only. Part names, hashes and original assembly transforms are recorded in the inventory.
Mechanical parameters and geometric accuracy have not been calibrated.

[`visual_meshbase/`](visual_meshbase/README.md) is the frozen, owner-reviewed appearance base (v2); it is not yet consumed by the build DAG, loaders or resource packages.

Runtime kinematics configuration is generated by `scripts/build_kinematics.py` into
`build/generated/kinematics/xbox_one_s.json`, with parameter evidence generated in the same directory.
When launching the existing viewer from the repository root, use `--assets assets/xbox_one_s/visual`;
see the main README for the remaining launch options.
